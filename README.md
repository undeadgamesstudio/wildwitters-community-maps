# Wildwitters Community Maps

Maps made by the Wildwitters community, built with the map editor at [editor.wildwitters.app](https://editor.wildwitters.app/).
Every week the community votes; the winner is featured in the game.

> Status: the repository is set up, the first submissions are not open yet. The submission rules below are a
> **draft**. They are not legal advice and will be final before the first map is accepted.

## What is in here

```
maps/<slug>/map.json          the map, in the game's map format
maps/<slug>/preview.png       preview picture (max. 768 x 1024)
maps/<slug>/meta.json         title, description, author (display name), submitted, rightsVersion, tags
maps/<slug>/assets/<id>.png   pictures the map uses (backdrop, animation strips)
seasons/<year>-w<week>.json   candidates and winner of each voting week
index.json                    list of all maps, generated by CI - do not edit by hand
scripts/validate.mjs          the checks CI runs on every change
```

Only approved maps are in this repository. Votes are not stored here (they belong to player accounts and live on
the game server); only the result of each week is.

## How a map gets here

1. Build the map in the editor. Use **Validate**: a map must be playable (bases, spawn tiles, a capture point,
   a way to the enemy base) and should be fair for both teams.
2. In the editor press **Upload map to Community Hub (weekly voting)**, give it a title and a description and
   confirm the rights (see [RIGHTS.md](RIGHTS.md)). The editor sends the map and a preview picture to the game server.
3. The server checks the map again and a moderator approves it.
4. A bot opens a pull request here. When it is merged the map is published and goes into the next vote.
5. After the vote the winner is written to `seasons/` and marked `featured` in `index.json`.

You can also open a pull request yourself with a map folder under `maps/`. It goes through the same checks.

## How the game uses it

When this repository changes, its CI publishes `maps/` and `index.json` to the game's static host. The game reads
`/community/index.json` and loads `/community/maps/<slug>/map.json` when a map is picked; maps and their pictures
are cached for offline play. Nothing here is built into the game itself, so a new map needs no new game version.

## Rules for maps and pictures

- Playable and fair: `scripts/validate.mjs` checks the same things as the editor's Validate button.
- Size: `map.json` at most 2 MB, each picture at most 2048 px on its longer side and 2 MB, at most 24 layers.
- Only your own work, or work you have the right to pass on. Nothing taken from the original game or from other
  people's artwork. No offensive pictures.
- Maps can be removed on request of the author or when a right turns out to be missing.

## Licence

There is **no licence file yet on purpose**: until the final wording is decided, the author keeps all rights and
only the rights text in [RIGHTS.md](RIGHTS.md) that you confirm on upload applies to a submitted map.
